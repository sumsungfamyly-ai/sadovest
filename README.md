# Садовест — Telegram Mini App + бот

Mini App (уроки, VIP, промокоды, огород и календарь полива, поддержка, игры, профиль, админ-панель) и Telegram-бот на одном проекте Vercel. Зависимостей нет, сборка не нужна.

## Структура
- `public/index.html` — приложение (интерфейс)
- `api/rpc.js` — API приложения (проверка подписи Telegram, уроки, промокоды, тикеты, админка)
- `api/bot.js` — вебхук бота (/start /help /vip /support /profile /promo + админ-команды)
- `api/setup.js` — одноразовая настройка вебхука и кнопки меню
- `api/cron.js` — ежедневные напоминания (полив, истечение VIP)
- `lib/lessons.js` — тексты уроков (10 бесплатных + 176 VIP, VIP-тексты замените на свои)
- `lib/news.js` — хранение новостей (Redis, ключ `news:list`; фото — ключи `news:img:ID`)
- `api/newsimg.js` — отдача фото новостей
- `lib/enc.js` — полные тексты энциклопедии (только на сервере; VIP-записи отдаются через API, в `public/enc.js` у них лишь название)
- `public/hacks2.js` — дополнительные лайфхаки (формат строки: категория|название|кратко|подробно; всего 120)
- `public/plant-recognition.js` — локальное распознавание растений по фото
- `scripts/dev-preview.mjs` — локальный предпросмотр с демо-данными (`npm run dev`)

## Локальный предпросмотр
1. Установите Node.js 18.17 или новее.
2. В терминале VS Code выполните `npm.cmd run dev` (в Windows PowerShell это обходит запрет запуска `npm.ps1`).
3. Откройте `http://127.0.0.1:4173`. Страница автоматически перезагружается при сохранении файлов проекта.

Предпросмотр использует демо-данные и имитацию API: он не подключается к Telegram, Vercel или Redis, а изменения данных не сохраняются. Распознавание фото работает в браузере на устройстве пользователя; снимок не отправляется в API или внешний сервис. При первом запуске браузер загружает модель примерно 154 МБ с Hugging Face и сохраняет её в кэше. Распознаватель предлагает только растения из каталога Садовеста, откуда берутся описание и VIP-доступ. Для проверки VIP и панели администратора добавьте `?vip=1&admin=1` к адресу. Это только локальный режим; для настоящего приложения используйте инструкции по публикации ниже.

## Запуск
1. @BotFather → /newbot → получите BOT_TOKEN.
2. Залейте проект в GitHub (новый репозиторий, загрузите все файлы из папки).
3. vercel.com → Add New → Project → выберите репозиторий → Framework Preset: Other → Deploy.
4. В проекте: Storage → Create/Connect → Upstash Redis (Marketplace). Переменные базы добавятся сами.
5. Settings → Environment Variables: BOT_TOKEN, ADMIN_IDS, WEBHOOK_SECRET, CRON_SECRET (= WEBHOOK_SECRET), BUY_URL.
   В BUY_URL можно использовать подстановки `{code}` (промокод скидки), `{discount}` (процент) и `{id}` (Telegram ID покупателя), например `https://pay.example/vip?promo={code}&uid={id}`.
6. Deployments → Redeploy.
7. Откройте в браузере один раз: https://ВАШ-ПРОЕКТ.vercel.app/api/setup?key=ВАШ_WEBHOOK_SECRET
8. В Telegram напишите боту /start и нажмите «Открыть Садовест».

## Админ
Ваш Telegram ID в ADMIN_IDS. В приложении появится «Панель администратора». В боте:
/news — последние новости (для всех), /grant ID дни, /newpromo КОД тип(vip|coins|discount) значение лимит дни, /stats, /reply ID текст.

## Что учтено в коде
- Запросы одного пользователя выполняются по очереди (блокировка в Redis), поэтому параллельные вызовы не затирают друг друга. Если блокировку получить не удалось за 5 секунд, запрос завершается с временной ошибкой вместо работы без защиты.
- Проверка `/api/health` проверяет Redis командой `PING` и не создаёт и не удаляет записи пользователей.
- Распознавание фото работает через локальную zero-shot-модель [CLIP](https://huggingface.co/Xenova/clip-vit-base-patch32) (лицензия MIT) в браузере, без API-ключей и без передачи фото на сервер. При первом использовании браузер скачивает файлы модели (около 154 МБ) и кэширует их; для первой загрузки нужен интернет. Кандидаты ограничены энциклопедией Садовеста, а VIP-статьи остаются закрыты для бесплатных аккаунтов. Модель может ошибаться: результат показывается как предположение и должен подтверждаться статьёй каталога.
- Интервал полива у растения можно изменить (`plant_interval`); название растения — до 40 символов, интервал — целое число от 1 до 60 дней.
- Промокоды: 10 попыток за 10 минут на пользователя; тикеты: 5 в час. Скидочный промокод сохраняется в профиле и показывается на экране VIP; при выдаче VIP администратором скидка сбрасывается.
- Рассылка и ежедневные напоминания учитывают лимиты Telegram; кто заблокировал бота, тому напоминания отключаются автоматически.
- Ни серии, ни счётчика дней в приложении нет: монеты начисляются за новые уроки и за улучшение результата в тестах.
- Тесты (`lib/tests.js`): 16 тематических по 15 вопросов, внутри каждого вопросы идут от лёгких к сложным (1–5, 6–10, 11–15). Три общих теста собирают по 20 вопросов из соответствующих групп всех тематических тестов без повторов. Номера (id) тестов не меняйте, по ним хранятся результаты; новые добавляйте в конец списка `T2`.
- В уроках в блоке «Новые слова» остаются только термины, которые действительно встречаются в тексте урока.
- Дизайн («Изумрудное сияние»): все стили в одном блоке `<style>` в `public/index.html`. Цвета и переливы заданы переменными в начале блока (`--irid`, `--irid-d`, `--irid-t`), тёмная тема меняет те же переменные. Анимации отключаются в настройках («Анимации») и при `prefers-reduced-motion`.
- Заставка (`#splash` в `public/index.html`, картинки в `public/img/splash/`): картина с анимацией (ken burns, солнечные лучи, блик на вывеске, летающие бабочки, блики на плодах, капли, пыльца и листья) и живая полоса загрузки: она плавно ползёт к ~90%, пока грузится приложение, и добегает до 100% по готовности. Чтобы заменить картину, подготовьте квадратное изображение и положите как `art.webp`; координаты слоёв заданы в процентах от картины.
- Сохранение данных: кнопки «Сохранить» обновляют экран на месте (`draw('soft')` / `draw('scroll')`): прокрутка, раскрытые блоки и введённый текст не сбрасываются, во время запроса кнопка показывает «Сохранение…».
- Варианты заставки: при каждом запуске выбирается сцена «утро», «день», «вечер», «ночь» или «дождь» (по времени суток с элементом случайности; одна и та же сцена два раза подряд не показывается). Для просмотра добавьте к адресу `?splash=night` (или `morning`, `day`, `evening`, `rain`). Внизу заставки показывается случайный совет из лайфхаков с уклоном в текущий сезон.
- Новости: раздел «Ещё → Новости» и карточка на главной (с пометкой «Новое»). Добавляйте, правьте, закрепляйте и удаляйте новости в «Панель администратора → Новости». Бот показывает последние 5 по команде /news (после этого один раз откройте `/api/setup?key=...`, чтобы команда появилась в меню).
- Фото и стили новостей: в «Панель администратора → Новости» можно выбрать фото (сжимается в браузере до ~1000 px) и поставить его сверху или фоном, выбрать стиль (обычный, изумрудный, золотой, радужный перелив, закат, океан, звёздная ночь), включить или выключить анимацию, закрепить новость. Снизу показывается живой предпросмотр.

- Уроки 172–186 (15 новых VIP): досветка рассады, биозащита, ловушки, однолетники, клематисы, террасы, квашение, травяные чаи, первый год на участке, вода для полива, актинидия и лимонник, инжир и хурма, формирование кроны, ошибки новичка, цветовые сочетания. Термины добавлены в словарь (`public/data3.js`).
- Кнопки v2: объёмные, с глянцем, нажатием, волной, состоянием загрузки и фокусом (блок «Кнопки v2» в конце `<style>`). Отключаются настройкой «Анимации».
- Распознавание фото v2 (`public/plant-recognition.js`): CLIP ViT-B/16 (q8), текстовые отпечатки каталога считаются один раз и кэшируются в IndexedDB, двойной просмотр (целиком + крупно) при низкой уверенности, прогрев при выборе фото, запасной режим на B/32. Показываются до трёх вариантов с процентами.

- Распознавание ~1000 растений: каталог (120, со статьями) + `public/plant-names.js` (880 дополнительных: овощи, ягоды, цветы, деревья, кустарники, хвойные, комнатные, травы). Формат строки `Русское название|English name`; добавляйте свои строки. Список обрабатывается один раз и кэшируется на устройстве.
